# Security Policy

## Supported versions

Security fixes are provided for the latest release in the 1.x series. Please
update to the latest release before reporting a vulnerability.

## Reporting a vulnerability

Please [report vulnerabilities privately through GitHub](https://github.com/tinusg/filament-hover-image-column/security/advisories/new).
Do not disclose security vulnerabilities in public issues or pull requests.

Include the affected package version, a description of the issue, and steps to
reproduce it. A minimal example is helpful; do not include credentials or other
sensitive data.

Reports are reviewed on a best-effort basis, with no guaranteed response time.
Follow-up questions and coordination of a fix will take place in the private
report before public disclosure.
